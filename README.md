# Droplet — «капля» для GNOME

Расширение GNOME Shell в стиле Dynamic Island: на месте часов в верхней панели живёт чёрная «капля», которая плавно перетекает между состояниями — как жидкость, без рывков и разрывов.

- **Свёрнутая** — время, как обычные часы; если играет музыка — мини-обложка и «живой» эквалайзер.
- **Короткие события** — капля ненадолго вытягивается и показывает: новый трек, уведомление, наушники подключены, зарядку, громкость, скопированные файлы.
- **Раскрытая** (щелчок по капле) — капля «стекает» из панели вниз и показывает виджеты.

> Неофициальный проект. «Dynamic Island» — название Apple; здесь только похожая идея.

## Виджеты

| Виджет | Что умеет |
|---|---|
| **Музыка и видео** | Обложка, название, прогресс с перемоткой, пауза / предыдущий / следующий — для любого плеера с MPRIS (Spotify, браузеры, mpv, VLC, Rhythmbox…). |
| **Звук** | Громкость и быстрый выбор устройства вывода: колонки, наушники, HDMI, Bluetooth. Колесо мыши над каплей тоже меняет громкость. |
| **Полка файлов** | Всё, что вы копируете в «Файлах» (Ctrl+C), появляется на полке. Отсюда файл можно открыть, показать в папке или снова скопировать и вставить в другую папку. |
| **Уведомления и статус** | Новые уведомления коротко появляются в капле (стандартный баннер GNOME при этом не дублируется, уведомление остаётся в списке). Зарядка, полный и низкий заряд батареи. |

Виджеты включаются и переставляются в настройках (⚙ в раскрытой капле или `gnome-extensions prefs droplet@buyakussia.github.io`).

**Правый щелчок** по капле открывает привычный календарь и список уведомлений GNOME.

## Как сделана анимация

Форма капли рисуется вручную и не является окном, поэтому может перетекать каждый кадр:

- **Пружинная физика** (как в iOS) вместо анимаций с фиксированной длительностью: у формы есть инерция, она слегка «перелетает» и успокаивается. Если состояние меняется посреди движения, капля просто меняет направление, сохраняя скорость, — поэтому нет рывков.
- **Перетекание формы**: пилюля внутри панели плавно превращается в каплю, которая «вытекает» из панели с вогнутыми скруглениями в месте отрыва.
- **Жидкий край**: при движении нижний край слегка провисает по направлению движения и пружинит обратно.
- Содержимое проявляется с небольшим опозданием и увеличением — словно всплывает из капли.
- В покое анимация не тратит процессор: кадры считаются только пока капля движется.

## Установка

Нужен GNOME 46–51 (Arch, Fedora, Ubuntu 24.04+ и др.).

```bash
git clone https://github.com/buyakussia/droplet.git && cd droplet
./install.sh
```

Затем **выйдите из системы и войдите снова**: на Wayland GNOME подгружает новые и обновлённые расширения только при входе. Обновление — `git pull && ./install.sh` и снова перезайти. Удаление — `./uninstall.sh` (`--purge` — вместе с настройками и полкой).

## Как добавить свой виджет

1. Создайте `extension/lib/widgets/мой.js` с классом, у которого есть:
   - `card` — карточка для раскрытой капли (любой `St.Widget`);
   - `compactPriority()` — число > 0, если виджет хочет показываться в свёрнутой капле (тогда нужны `compactLeading` / `compactTrailing`);
   - необязательно `onStateChanged(state)` и обязательно `destroy()`.
   Конструктор получает `ctx`: `ctx.island.showActivity({icon, title, subtitle, progress, duration, onClick})` показывает короткое событие, `ctx.settings` — настройки, `ctx.compactChanged()` — попросить перерисовать свёрнутую каплю.
2. Зарегистрируйте класс в `extension/lib/registry.js` (`CLASSES`) и добавьте описание в `extension/lib/catalog.js` — он сразу появится в настройках.

## Структура

```
extension/
  extension.js        включение / выключение
  lib/island.js       капля: состояния, жесты, раскладка
  lib/spring.js       пружинная физика и покадровый «двигатель»
  lib/shape.js        форма капли (cairo)
  lib/registry.js     набор виджетов и раскрытая капля
  lib/status.js       уведомления и батарея
  lib/mpris.js        клиент MPRIS (плееры)
  lib/widgets/        музыка, звук, полка
  prefs.js            окно настроек
  schemas/            настройки (GSettings)
```
