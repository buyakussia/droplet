# Droplet — «капля» для GNOME

Расширение GNOME Shell в стиле Dynamic Island — смесь идей Alcove и Droppy для macOS. На месте часов в верхней панели живёт чёрная «капля», которая плавно перетекает между состояниями, как жидкость, без рывков и разрывов.

- **Свёрнутая** — время, как обычные часы. Если играет музыка — мини-обложка и «живой» эквалайзер; если идёт таймер — кольцо прогресса и обратный отсчёт.
- **Подглядывание** — наведите курсор: капля чуть расширяется и показывает бегущую строку с названием трека.
- **Громкость и яркость** — тонкая полоска прямо в капле вместо стандартного окошка GNOME.
- **Короткие события** — новый трек, уведомление (стандартный баннер не дублируется), наушники подключены, зарядка, файлы на полке, конец Pomodoro.
- **Раскрытая** (щелчок) — капля «стекает» из панели, а под ней отделяется маленькая капелька вкладок — с жидкой перемычкой в момент отрыва.
- **Перетащите файлы на каплю** — она раскроется в зону «Отпустите, чтобы положить на полку».

> Неофициальный проект. «Dynamic Island» — название Apple; здесь только похожая идея.

## Вкладки

| Вкладка | Что умеет |
|---|---|
| **Музыка и видео** | Как в Alcove: обложка, название, прогресс со временем с обеих сторон и перемоткой, «перемешать», пауза / назад / вперёд и выбор устройства вывода прямо в плеере. Любой плеер с MPRIS (Spotify, браузеры, mpv, VLC…). |
| **Календарь и погода** | Дата, ближайшие события сегодня и завтра (календари GNOME / онлайн-аккаунты), погода из приложения «Погода». |
| **Звук** | Общая громкость, устройства вывода (колонки, наушники, HDMI, Bluetooth) и громкость **отдельно для каждого приложения**. |
| **Полка** | Файлы, скопированные в «Файлах» (Ctrl+C) или перетащенные на каплю: открыть, показать в папке, снова скопировать. |
| **Буфер обмена** | Последние записи из Clipboard History (приложение из проекта Lens); щелчок — снова в буфер. |
| **Заметки** | Маленький блокнот, сохраняется сам. |
| **Pomodoro** | Фокус → перерыв → фокус… со звуком и событием в капле; длительности настраиваются. |
| **Система** | Процессор, память, видеокарта (AMD), диск, батарея, сеть. |

Вкладки включаются и переставляются в настройках (⚙ в раскрытой капле или `gnome-extensions prefs droplet@buyakussia.github.io`). **Правый щелчок** по капле открывает привычный календарь и список уведомлений GNOME. Колесо мыши над каплей — громкость.

**Вид** (в настройках):
- **Форма капли:** «Остров» — парит под краем экрана со скруглением со всех сторон, как Dynamic Island (по умолчанию); «Вырез» — прилегает к краю и «стекает» из панели, как вырез MacBook.
- **Прозрачная верхняя панель** — обои видны насквозь, а капля становится настоящей чёрной пилюлей. Как только окно касается панели (развёрнуто или придвинуто), панель снова становится непрозрачной. У текста и значков панели лёгкая тень — читаются и на светлых обоях.

**Экран блокировки.** На нём капля тоже работает, но показывает только безопасное: плеер и таймер. Уведомления, файлы, буфер и заметки там не видны.

## Как сделана анимация

Форма капли рисуется вручную и не является окном, поэтому может перетекать каждый кадр:

- **Пружинная физика** (как в iOS) вместо анимаций с фиксированной длительностью: у формы есть инерция, она слегка «перелетает» и успокаивается. Если состояние меняется посреди движения, капля просто меняет направление, сохраняя скорость, — поэтому нет рывков.
- **Перетекание формы**: пилюля внутри панели плавно превращается в каплю, которая «вытекает» из панели с вогнутыми скруглениями в месте отрыва.
- **Жидкий край**: при движении нижний край слегка провисает по направлению движения и пружинит обратно.
- Капелька вкладок выходит из-под капли и отрывается с жидкой перемычкой; подсветка активной вкладки перелетает на пружине и чуть «растягивается» в полёте.
- При смене вкладки капля перетекает под размер новой страницы.
- Содержимое проявляется с небольшим опозданием и увеличением — словно всплывает из капли.
- В покое анимация не тратит процессор: кадры считаются только пока капля движется.

## Установка

Нужен GNOME 46–51 (Arch, Fedora, Ubuntu 24.04+ и др.).

```bash
git clone https://github.com/buyakussia/droplet.git && cd droplet
./install.sh
```

Затем **выйдите из системы и войдите снова**: на Wayland GNOME подгружает новые и обновлённые расширения только при входе. Обновление — `git pull && ./install.sh` и снова перезайти. Удаление — `./uninstall.sh` (`--purge` — вместе с настройками и полкой).

## Как добавить свой виджет

1. Создайте `extension/lib/widgets/мой.js` с классом, у которого есть:
   - `page` — страница вкладки (любой `St.Widget`);
   - `lockSafe` — можно ли показывать на экране блокировки;
   - `compactPriority()` — число > 0, если виджет хочет показываться в свёрнутой капле (тогда нужны `compactLeading` / `compactTrailing`);
   - необязательно `peekText()` (бегущая строка при наведении), `onPageShown(shown)`, `onStateChanged(state)`; обязательно `destroy()`.
   Конструктор получает `ctx`: `ctx.island.showActivity({icon, title, subtitle, progress, duration, onClick, private})` показывает короткое событие, `ctx.settings` — настройки, `ctx.compactChanged()` — перерисовать свёрнутую каплю, `ctx.relayout()` — страница поменяла размер, `ctx.showTab(id)` — раскрыть каплю на вкладке.
2. Зарегистрируйте класс в `extension/lib/registry.js` (`CLASSES`) и добавьте описание и значок в `extension/lib/catalog.js` — вкладка сразу появится в капле и в настройках.

## Структура

```
extension/
  extension.js        включение / выключение
  lib/island.js       капля: состояния, жесты, раскладка
  lib/spring.js       пружинная физика и покадровый «двигатель»
  lib/shape.js        форма капли, капелька вкладок и жидкая перемычка (cairo)
  lib/tabbar.js       вкладки с перелетающей подсветкой
  lib/registry.js     вкладки, свёрнутая капля, экран блокировки
  lib/osd.js          громкость и яркость в капле вместо окошка GNOME
  lib/drop.js         перетаскивание файлов на каплю
  lib/status.js       уведомления и батарея
  lib/sound.js        общие функции звука
  lib/mpris.js        клиент MPRIS (плееры)
  lib/widgets/        музыка, календарь, звук, полка, буфер, заметки, Pomodoro, система
  prefs.js            окно настроек
  schemas/            настройки (GSettings)
```
