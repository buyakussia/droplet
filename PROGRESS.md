# Droplet — состояние работы (для продолжения)

_Обновлено: 27 ноября 2026. Версия 0.2 — готова в `main`, ждёт проверки пользователем на GNOME 51._

## Что просил пользователь
«Смесь» двух приложений для macOS из присланных роликов:
- **Alcove** — минималистичный Dynamic Island вокруг музыки;
- **Droppy** — «комбайн» с вкладками и расширениями.

Выбрано пользователем (всё ниже — нужно):
- Alcove: подглядывание при наведении (бегущая строка), громкость/яркость в капле вместо окошка GNOME,
  плеер как в Alcove (время с обеих сторон, «перемешать», выбор устройства вывода), плеер на экране блокировки.
- Droppy: громкость по приложениям, Pomodoro, быстрые заметки, статистика системы.
- Раскладка: **вкладки как в Droppy** (отдельная капелька вкладок под каплей).
- Ещё: перетаскивание файлов на каплю, история буфера (из Clipboard History), календарь и погода.

## Сделано и проверено во вложенном GNOME Shell 46 (в контейнере)
- `lib/island.js` — состояния compact / peek / activity / hud / drop / expanded; вкладки; уход курсора
  проверяется по расстоянию (`_watchLeave`), чтобы смена вкладки не сворачивала каплю.
- `lib/shape.js` — капля + капелька вкладок + жидкая «перемычка» в момент отрыва (reach = 9 < зазора 10).
- `lib/tabbar.js` — вкладки; подсветка перелетает на пружине и «растягивается» в полёте.
- `lib/registry.js` — вкладки по настройке `widgets`, `active-tab`, экран блокировки (`_syncLock`),
  раскрытие на «живом» виджете (таймер/музыка).
- Вкладки (`lib/widgets/`): media (Alcove), calendar, audio (+по приложениям), shelf, clipboard, notes,
  pomodoro, system — все 8 открываются и выглядят нормально.
- `lib/osd.js` — подмена `Main.osdWindowManager` (GNOME 46: show(monitor, icon, label, level, max);
  48+: show(icon, label, levels) + showOne/showAll). Проверено: полоска «45» в капле.
- Подглядывание (бегущая строка «трек — исполнитель») — проверено.
- Заметки: ввод с клавиатуры через `Main.pushModal` — проверено.
- Pomodoro: кольцо + отсчёт в свёрнутой капле — проверено.
- Экран блокировки: только безопасные вкладки (media, pomodoro), **без панели вкладок**
  (с ней был артефакт отрисовки в тестовом режиме блокировки), кнопка настроек скрыта,
  уведомления/файлы с флагом `private` не показываются. Проверено через `DROPLET_TEST_LOCK`.
- Исправлено: в новых GNOME нет `event.get_source()` → используем `global.stage.get_event_actor(e)`.

## Как тестировать (контейнер)
Скрипты в scratchpad (могут пропасть): вложенный `gnome-shell --nested --wayland` внутри Xvfb `:98`,
нужен системный D-Bus (`dbus-daemon --system --fork`), тестовый MPRIS-плеер на gjs, `xdotool` для щелчков.
Капелька вкладок ищется на скриншоте как самый нижний чёрный участок в столбце x=800.
